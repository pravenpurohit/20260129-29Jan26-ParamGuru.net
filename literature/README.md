# Literature Reference

This directory contains reference materials (PDFs, Word documents, Books) for the website content.

**Usage Rules:**
1.  **Not for Public**: Files in this folder are **NOT** served to the website visitors. Do not link to them directly in `src` or `public`.
2.  **Reference Only**: These documents serve as source material. Content should be extracted, modified, or summarized before being added to the website text.
3.  **For the AI**: When asking the AI to generate content, direct it to look in this folder for source material.
